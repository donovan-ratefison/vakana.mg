# Changelog

This file records all notable changes to this project.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-10

First public source release, under the Apache License 2.0. The development
of earlier versions (to 0.89.1) was in a private repository. This file
starts here.

### Changed

- The text in the app and in the guides uses Simplified Technical English.
- The fixed text in Org, Markdown and slide exports has new punctuation.
  For example, an Org comment headline is now `Comment: [timestamp]`.
